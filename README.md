# DCX-wastewater-process

## 项目概述
本仓库用于跟进 **DCX 污水处理 PCBA 项目** 的被动器件采购、报价与生产协调工作。

## 项目职责与范围

### 1. 主要职责
- 负责 PCBA 的生产协调
- 被动器件的寻价、采购
- 向 **德创鑫徐工** 提供最终报价

### 2. 器件范围
- 仅限**被动元件**：电阻、电容、二极管、三极管、TVS 等
- **不包含**：MCU、各类模块
- 所有器件均按**最小包装（MOQ）** 采购

### 3. 报价流程
1. 收集供应商报价
2. 严格考虑每个器件的 **MOQ（最小订单量）**
3. 计算**每个 PCBA 的单板成本**
4. 多余物料（Excess）采购成本 **平摊** 到每个 BOM / PCBA 中

### 4. 文档管理
- `Original_BOMs/` 目录存放原始五个 BOM 文件
- 所有文件变更必须记录**更改人 + 时间**

## 目录结构
- `Original_BOMs/` ：原始 BOM 文件
- `progress.md` ：项目进度跟踪
- `Quotation/` ：报价计算文档（后续创建）
